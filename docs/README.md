# OctoAcme Project Management Docs

This directory contains the core project management guidance used by OctoAcme to run work from idea through delivery and continuous improvement.

## Overview

OctoAcme uses a lightweight, cross-functional project management approach that emphasizes customer value, clear ownership, iterative delivery, and measurable outcomes. The process follows a practical lifecycle:

- Initiation: confirm the problem, stakeholders, desired outcomes, and whether the work should move forward.
- Planning: turn the approved initiative into a prioritized backlog, timeline, milestones, and dependencies.
- Execution: deliver in small increments, monitor work, track risks, and maintain quality with reviews and testing.
- Release & Deployment: validate readiness, deploy with checks, and verify the outcome.
- Retrospective & Improvement: capture lessons learned and convert them into action items for the next cycle.

## How to use these docs

- Start with the [Project Management Overview](./octoacme-project-management-overview.md) for a high-level view.
- Use the initiation and planning docs when a new effort is being shaped.
- Refer to execution, risk, and release docs during delivery and deployment.
- Capture learnings in retrospectives to improve the next project cycle.
